# Apple Clock для Android

Самостоятельная Android-версия [Apple Clock для Windows](https://github.com/MaksimDenisov31/apple-clock-apple-design). Интерфейс на русском языке по мотивам приложения «Часы» на iPhone: чёрная тёмная тема, светлая тема, оранжевые акценты, крупные цифры, круглые кнопки и плавающая нижняя панель. Выбор темы и существующие данные сохраняются при обновлении.

Внизу доступны мировые часы, будильники, секундомер и таймеры. Фокусировка и настройки находятся в «Ещё». Кнопка «+» вверху добавляет таймер, будильник или город. Нажатие на время будильника открывает редактор; Для удаления будильника удерживайте его время, для удаления города — его строку; затем подтвердите удаление. Вверху всех вкладок отображается Apple Clock, кнопки «Править / Готово» убраны. В редакторах часы, минуты и секунды выбираются прокруткой; ручной ввод и точная настройка кнопками сохранены.

Ориентиры оформления: [таймеры iPhone](https://support.apple.com/guide/iphone/set-timers-iph8241d6b2a/ios) и [обновлённый дизайн Apple](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/). Панель навигации использует лёгкий полупрозрачный градиент без постоянного размытия содержимого экрана.

## Установка на Samsung

1. Скачайте [AppleClock-Android-1.1.4.apk](https://github.com/MaksimDenisov31/apple-clock-android/releases/download/v1.1.4/AppleClock-Android-1.1.4.apk) на телефон (Android 8.0 или новее).
2. Откройте файл через «Мои файлы» и разрешите установку из этого источника. Если установка запрещена «Автоблокировкой» Samsung, разрешите её в настройках телефона; после установки защиту можно включить обратно.
3. Запустите Apple Clock и разрешите уведомления. В разделе «Ещё» проверьте доступ к точным сигналам. На Android 12 может понадобиться отдельное разрешение точных сигналов.
4. При подсказке «Будильник без разблокировки» нажмите «Разрешить показ» и включите полноэкранные уведомления. На Samsung также разрешите уведомления Apple Clock на экране блокировки. Если подсказка закрыта, откройте «Ещё → Настройки → Управление на экране блокировки». Для кнопок уведомления разверните его.
5. При ограничениях Samsung добавьте часы в «Обслуживание устройства → Батарея → Ограничения в фоновом режиме → Никогда не спящие приложения». Названия пунктов зависят от версии One UI.

Громкость **будильников телефона** и режим «Не беспокоить» влияют на слышимость. Громкость приложения регулируется отдельно. Перед использованием утром проверьте короткий таймер на своём телефоне с заблокированным экраном.

Для обновления устанавливайте новый APK поверх прежнего, без удаления приложения: тема, таймеры, будильники, города и настройки сохранятся. APK универсальный, без нативных библиотек, подходит для ARM/ARM64 Samsung.

## Возможности

Версия 1.1.4: единая верхняя надпись Apple Clock на всех вкладках, без «Править / Готово». [Проверка интерфейса и снимки](docs/headers-verification.md).

Версия 1.1.3: будильник включает экран и показывает кнопки остановки и повтора через две минуты поверх блокировки при разрешённом полноэкранном доступе. Действия доступны также в развёрнутом уведомлении без ввода PIN. Запуск любого нижнего таймера переносит его в большой круг наверху; пауза и сброс больше не пересоздают весь экран. [Проверка с PIN и реальные снимки](docs/lockscreen-timers-verification.md). Проверено на Android 15 в эмуляторе; Samsung One UI и динамик телефона требуют отдельной проверки на устройстве.

- Несколько именованных таймеров от 1 секунды до 99:59:59, пауза, сброс, редактирование, удаление; быстрый старт 1/5/10/15/30 минут. Шаг стрелок от 1 до 3600 секунд.
- Будильники один раз или по дням недели, включение и отключение, откладывание на 2 минуты.
- Секундомер с кругами; при сворачивании продолжает отсчёт на монотонных часах. После перезагрузки телефона секундомер сбрасывается.
- Мировые часы: 16 городов, поиск, даты, секунды, правила часовых поясов IANA и летнее время.
- Фокусировка: задача, рабочий интервал, перерыв, пауза и счётчик завершённых сессий. Следующий интервал запускается вручную после подтверждения сигнала.
- Обе темы, автономная работа без интернет-разрешения, встроенный перезвон Koshi, отдельная громкость.
- Точные сигналы через AlarmManager; восстановление расписания после перезагрузки и обновления APK; мелодия повторяется до подтверждения. Каждый из нескольких одновременных сигналов подтверждается отдельно.

Таймеры и будильники продолжают работать после сворачивания и удаления из недавних приложений. Принудительная остановка через настройки Android блокирует сигналы до следующего запуска. При выключенном телефоне сигналов нет. После включения просроченные таймеры срабатывают; будильники старше 10 минут пропускаются. Ограничения производителя, разрешений и энергосбережения могут влиять на фоновую доставку. На разблокированном экране система может показывать уведомление вместо открытия полноэкранного сигнала.

Данные хранятся в закрытом хранилище приложения, не передаются в сеть. Настройки Windows автоматически не импортируются. Исходный Windows-проект не изменяется.

## Сборка

Нужны Python 3, JDK 11+ и официальные Android SDK Platform 35 / Build Tools 35.0.0. Сборка не использует Gradle, Android Studio или внешние Java-библиотеки:

```powershell
python tools/build.py --sdk C:/Android/Sdk --jdk C:/Java/jdk-17
```

Скрипт компилирует Java и ресурсы, выполняет D8, zipalign, подписывает APK и проверяет подпись; результат в `dist/`. SDK можно указать через `ANDROID_HOME`, JDK через `JAVA_HOME`. Ключ выпуска генерируется единожды в `.tools/apple-clock-release.jks`, пароль — в `.tools/signing.json`. **Сохраните оба файла в защищённой резервной копии**: они необходимы для обновлений с сохранением данных. Они исключены из Git и из выпуска. Не подменяйте ключ при последующих сборках.

Проверка логики:

```powershell
javac -encoding UTF-8 -d build/logic app/src/main/java/com/maksimdenisov/appleclock/ClockLogic.java app/src/main/java/com/maksimdenisov/appleclock/ScheduleCache.java tools/LogicTest.java tools/SchedulingTest.java
java -cp build/logic LogicTest
java -cp build/logic com.maksimdenisov.appleclock.SchedulingTest
```
