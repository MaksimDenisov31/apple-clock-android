# Проверка версии 1.0.0

- Сборка: официальные Android SDK Platform 35 и Build Tools 35.0.0, Microsoft JDK 11.
- Java скомпилирована, D8 выполнен, APK выровнен zipalign и подписан постоянным ключом выпуска.
- apksigner verify: подпись v2 и v3 действительна, один подписант; minSdk 26, targetSdk 35, отсутствуют нативные библиотеки и разрешение INTERNET.
- 17 проверок ClockLogic: допустимые и недопустимые длительности, округление секунд, работа и пауза отсчёта, предел нуля, будильник сегодня/завтра, воскресенье, будние дни и переход DST в Нью-Йорке. Выполнены успешно.
- Проверены целостность ZIP-контейнера APK и наличие несжатой встроенной WAV-мелодии, пригодной для MediaPlayer.openRawResourceFd.

## Что не удалось проверить

Запуск APK в Android, визуальные снимки обеих тем, касания, диалоги, реальное воспроизведение, срабатывание фоновых сигналов, восстановление после перезагрузки и обновление поверх предыдущей установки **не проверены на работающей Android-системе**. Эти функции реализованы в исходниках, но сборка и проверки чистой логики не подтверждают их работу на устройстве.

На компьютере отсутствует драйвер аппаратного ускорения Android Emulator. Официальный Emulator 37.4.1 с образом Android 15 / API 35 не загрузил гостевую ОС в двух программных конфигурациях (включая одно ядро и отключённый Vulkan): ADB оставался offline. Системные драйверы и настройки виртуализации компьютера не изменялись. Неуспешная попытка запуска эмулятора не считается проверкой интерфейса.

Физический Samsung не подключён. Слышимость динамика, режим «Не беспокоить», энергосбережение One UI и доставка сигналов на конкретной модели требуют проверки на самом телефоне. Частота кадров на физическом экране не измерялась.
